# Contributing

Submitted contributions intended for inclusion in Aleph are accepted under the
Apache License 2.0, as described in section 5 of [LICENSE](LICENSE). Do not submit
work you are not entitled to contribute. No separate contributor license agreement
is required by this snapshot.

Keep changes focused, include a regression test when practical, and explain how
you tested them. Preserve third-party copyright, license and attribution notices.
Do not commit credentials, private user data, logs, caches or generated builds.

Respect [TRADEMARKS.md](TRADEMARKS.md); the source license does not license Aleph's
name, logo, mascot or official branding.
