# docs/guia — el conocimiento del Guía

Esta carpeta es la **base de conocimiento del Guía padrino** (CUARTO HONESTO §5–§6).
Cada archivo explica una superficie del producto en prosa larga: lo que en la UI
queda como una etiqueta corta, acá vive completo. El Guía lee estos MD como
contexto (poder **SABE**) para responder mejor que cualquier card fija.

## Organización

Un par de archivos por superficie, español + inglés:

| Superficie | ES | EN |
|------------|----|----|
| El Cuarto (taller / diorama) | `cuarto.es.md` | `cuarto.en.md` |
| La Sala (uso del agente) | `sala.es.md` | `sala.en.md` |
| Conectar (conectores / catálogo) | `conectar.es.md` | `conectar.en.md` |
| Modelos (cognición) | `cerebros.es.md` | `cerebros.en.md` |
| Piezas (piezas del Cuarto / closets / plan) | `piezas.es.md` | `piezas.en.md` |
| Memoria (herencia / memoria de cuenta) | `memoria.es.md` | `memoria.en.md` |

## Reglas de estos documentos

- **Fuente única de la explicación larga.** Si un concepto se explica acá, la UI
  no repite la pared de texto: muestra una etiqueta corta y el Guía trae el resto.
- **ES/EN paritarios.** Cada `*.es.md` tiene su espejo `*.en.md` con las mismas
  secciones. Al editar uno, edita el otro.
- **Español neutro/formal.** Sin voseo casual. Registro consistente con la copy
  de la app ("Puedes", "tu agente", "Asígnale…").
- **Verdad, no marketing.** Estos textos describen lo que el producto hace de
  verdad (las dos leyes de §0: fallo visible, estado + camino visible).
